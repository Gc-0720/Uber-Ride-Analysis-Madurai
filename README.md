# Uber Ride Analysis – Madurai

## Project Overview
This project analyzes Uber ride data in Madurai using MySQL to understand ride patterns, revenue, customer behavior and operational performance.

## Objectives
- Analyze completed and cancelled rides.
- Calculate total revenue and average fare.
- Compare vehicle types.
- Analyze payment methods.
- Identify popular pickup locations.
- Study driver performance and cancellation reasons.
- Understand daily and monthly ride trends.

## Dataset
The project uses four CSV datasets:
- Rides
- Riders
- Drivers
- Locations
